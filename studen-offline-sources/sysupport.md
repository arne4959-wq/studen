## ภาพรวม

สรุปสไลด์วิชา System Support ทั้ง 180 หน้า 12 บท พร้อมแบบทดสอบ 15 ข้อและเฉลยท้ายเอกสาร บทที่ 1–8 เป็นพื้นฐานคอมพิวเตอร์ตามหนังสือ Computing Essentials ส่วนบทที่ 9–12 เจาะลึกฮาร์ดแวร์ ได้แก่ CPU, RAM, Hard disk และ Mainboard

วิธีใช้: อ่านสรุปทีละบท แล้วทำแบบทดสอบโดยปิดเฉลยไว้ก่อน คำศัพท์สำคัญคงภาษาอังกฤษไว้ตามสไลด์

## บทที่ 1 · IT, Internet และตัวเรา

ระบบสารสนเทศมี 5 ส่วน และ People คือส่วนที่สำคัญที่สุด

- **ระบบสารสนเทศ (Information System)**: **People** (ผู้ใช้/End user), **Procedure** (ขั้นตอน/คู่มือ), **Software**, **Hardware**, **Data**
- **Data** = ข้อมูลดิบ (raw data) ที่ยังไม่ผ่านการประมวลผล → ประมวลผลแล้วเป็น **Information**
- **Software** มี 2 แบบ
  - **System software**: OS (Windows, Mac OS), **Utilities** (ดูแลทรัพยากรเครื่อง), **Device drivers** (ให้อุปกรณ์สื่อสารกับเครื่องได้)
  - **Application software**: แบบพื้นฐาน (browser, word processor, spreadsheet, presentation) และแบบเฉพาะทาง (กราฟิก, เสียง-วิดีโอ, multimedia, เว็บ, AI)
- **คอมพิวเตอร์ 4 ชนิด**: Supercomputer, Mainframe, Minicomputer, Microcomputer (Microcomputer มี 6 แบบ: Desktop, Laptop, Netbook, Tablet, Smartphone, Media Center)
- **ฮาร์ดแวร์ 4 กลุ่ม**: System unit (CPU + memory), Input/Output, Secondary storage (HDD, USB, flash card, CD/DVD/Blu-ray), Communication devices
- **ไฟล์ 4 แบบ**: Document (word processor), Worksheet (spreadsheet), Database (DBMS), Presentation
- **Connectivity**: Internet คือเครือข่ายที่ใหญ่ที่สุดในโลก, WWW, wireless revolution, **Cloud computing**
- **อาชีพ IT**: Webmaster, Computer support specialist, Technical writer, Software engineer, Network administrator, Database administrator, System analyst, Programmer

## บทที่ 2 · Internet, Web และ E-commerce

Internet เริ่มปี 1969 จาก ARPANET ส่วน Web เริ่มปี 1991 ที่ CERN อย่าสับสนสองอันนี้

- **Internet** เกิดปี **1969** จากโครงการ **ARPANET** ของสหรัฐฯ ขณะเชื่อมต่อเรียกว่า online
- **Web** เกิดปี **1991** ที่ **CERN** (องค์กรวิจัยนิวเคลียร์ยุโรป) เป็นสื่อ multimedia ที่เข้าถึงทรัพยากรบน Internet
- ใช้ทำ: Communicating, Shopping, Searching, Entertainment, Education
- เข้าใช้ผ่าน **Provider** (แบบมีสาย/ไร้สาย) + **Browser**
- **URL** = Protocol + Domain name · **HTML** = ภาษาเขียนเว็บ มี hyperlink · **JavaScript** เขียนร่วมกับ HTML · **Applet** = โปรแกรมเล็กที่เขียนด้วย Java
- **E-mail** = header (ที่อยู่, subject, ไฟล์แนบ) + message + signature · กัน spam ด้วย spam blocker · **Instant Messaging (IM)** คุยทันที
- **Social network** (สไลด์ให้ 6 แบบ): Identity, Creative, Interest, Collaboration, P2P, Virtual Reality
- **Blog** = บันทึกออนไลน์ · **Microblog** = ข้อความสั้นๆ · **Wiki** = ผู้อ่านช่วยกันเขียนและแก้ได้
- **การค้นหา**
  - **Spider** = โปรแกรมที่เก็บหน้าเว็บใหม่เข้าฐานข้อมูล
  - **Search engine** มี Keyword search (ผลที่เจอเรียก hits) และ Directory search
  - **Metasearch engine** = ส่งคำค้นไปหลาย engine พร้อมกัน แล้วตัดผลซ้ำ
  - **Specialized search engine** = ค้นเฉพาะเรื่อง
  - ประเมินเนื้อหาเว็บจาก authority, accuracy, objectivity, timeliness
- **E-commerce 3 แบบ**
  - **B2C** — โตเร็วที่สุด เช่น online banking, ซื้อหุ้น, ช้อปออนไลน์
  - **C2C** — นิยมสุดคือ การประมูล (auction house sites / person-to-person auction sites)
  - **B2B** — ธุรกิจกับธุรกิจ เช่น ผู้ผลิตกับผู้จัดหาวัตถุดิบ
- จ่ายเงินออนไลน์ 3 แบบ: check, credit card, electronic cash

## บทที่ 3–4 · Application Software

Application software แบ่งเป็นแบบพื้นฐานที่ทุกอาชีพใช้ และแบบเฉพาะทางสำหรับงานเฉพาะอาชีพ

- **GUI** ประกอบด้วย menu, dialog box, toolbar, ribbon, tab, gallery
- **โปรแกรมพื้นฐาน**: word processor, spreadsheet, database, presentation
- **กราฟิก**
  - **Desktop publishing** = จัดหน้าสิ่งพิมพ์ (page layout)
  - **Image editor / Photo editor** → ภาพ **Bitmap/Raster** เก็บเป็นจุด เรียกว่า pixels
  - **Illustration / Drawing program** → ภาพ **Vector** เก็บเป็นวัตถุ เช่น เส้น สี่เหลี่ยม วงรี
  - **Image gallery** = คลังภาพ (stock photographs, clip art) · **Graphics suite** = ชุดโปรแกรมกราฟิกหลายตัวรวมกัน
- **Video editing** ตัดต่อ เพิ่ม effect · **Audio editing** ใส่ filter แก้ track สร้างไฟล์ MP3
- **Multimedia** รวมวิดีโอ เพลง เสียง กราฟิก ตัวอักษร หัวใจคือ interactivity
- **Apps & App store** บนมือถือ
- **AI** มี 3 สาขา: Virtual reality, Knowledge-based systems, Robotics

## บทที่ 5 · System Software

System software มี 4 ประเภท: OS, Utility, Device driver และ Language translator

- **OS** ทำ 3 อย่าง: จัดการทรัพยากร, ทำ user interface, ทำงานร่วมกับโปรแกรม
- **Booting**: Start = **cold boot** · Restart = **warm boot**
- ส่วนติดต่อผู้ใช้: icon, pointer, window, menu, dialog box, Help · **file** เก็บข้อมูล/โปรแกรม · **folder** เก็บไฟล์
- **OS 3 แบบ** (เรียกอีกอย่างว่า platform)
  - **Embedded OS** — ฝังใน ROM ของอุปกรณ์พกพา/มือถือ
  - **Network OS (NOS)** — อยู่บน server ควบคุมเครือข่ายและ client
  - **Stand-alone / Desktop OS** — อยู่บน hard disk เช่น Windows, Mac OS, Linux
- **Virtualization** = รันหลาย OS/platform บนเครื่องเดียว แต่ละระบบแยกกันอิสระ
- **Mobile OS**: iOS, Android, Windows Phone, BlackBerry OS, Symbian
- **Utility ใน Windows** (เมนู System Tools): Backup and Restore, Disk Cleanup, Disk Defragmenter
- **Device driver** = โปรแกรมที่ทำให้อุปกรณ์ input/output สื่อสารกับคอมพิวเตอร์ได้

## บทที่ 6 · System Unit

System unit ของ microcomputer มีส่วนหลัก 3 อย่าง: system board, microprocessor และ memory

- System unit มี 6 แบบ: desktop, media center, notebook, netbook, tablet PC, handheld
- **System board / Motherboard** มี **socket** (เสียบชิป), **slot** (เสียบการ์ด), **bus line** (ทางส่งข้อมูล)
- **CPU** = **Control unit** (คุมให้ทำงานตามคำสั่ง) + **ALU** (คำนวณ arithmetic และ logical)
- **Memory 3 แบบ**
  - **RAM** — volatile ไฟดับข้อมูลหาย (เกี่ยวข้อง: cache memory, DIMM, virtual memory)
  - **ROM** — nonvolatile เก็บคำสั่งพิเศษ เช่น BIOS chip
  - **Flash memory** — ได้ข้อดีของ RAM + ROM ไม่มีไฟก็เก็บข้อมูลได้
- **Expansion card**: graphics, sound, NIC, wireless network, TV tuner · โน้ตบุ๊กใช้ PC card (PCMCIA) / ExpressCard ขนาดเท่าบัตรเครดิต
- **Bus width** = จำนวนบิตที่ส่งได้ต่อครั้ง · **System bus** = CPU ↔ memory · **Expansion bus** = CPU ↔ slot (USB, FireWire, PCIe)
- **Port**
  - มาตรฐาน: VGA/DVI (จอ), USB, FireWire, Ethernet
  - แบบพิเศษ: S/PDIF (เสียง/home theater), HDMI (ภาพ+เสียงดิจิทัล), MIDI (ดนตรีดิจิทัล)
  - **Legacy**: serial, parallel, keyboard, mouse, IrDA (อินฟราเรด)
- **Power supply** แปลงไฟ **AC → DC** · โน้ตบุ๊กใช้ AC adapter

## บทที่ 7 · Input และ Output

Input แปลงสิ่งที่คนให้เป็นข้อมูลที่คอมประมวลผลได้ ส่วน Output แปลงผลลัพธ์กลับเป็นรูปที่คนเข้าใจ

- **Keyboard**: traditional, flexible (พับ/ม้วนได้), ergonomic, wireless, PDA keyboard, virtual keyboard
- **Pointing device**: mouse (optical, mechanical, cordless), trackball, touch pad, pointing stick, touch screen, joystick, light pen, stylus
- **Scanning device**
  - Optical scanner: แบบ flatbed, document, portable
  - Card reader: แถบแม่เหล็ก และ RFID
  - Bar code reader อ่านรหัส **UPC** (แบบมือถือ / แบบติดตั้ง)
  - **MICR** = อ่านอักษรหมึกแม่เหล็ก · **OCR** = อ่านตัวอักษรด้วยแสง · **OMR** = อ่านเครื่องหมายด้วยแสง
- **Image capturing**: กล้องดิจิทัล, กล้องวิดีโอดิจิทัล · **Audio input**: microphone, sound card, ซอฟต์แวร์รู้จำเสียง
- **Monitor** → ผลบนจอเรียก **soft copy**
  - จอแบน **LCD** เป็นมาตรฐาน · **CRT** ใหญ่ กินไฟ กินที่
  - จอเฉพาะงาน: e-book reader, data projector, digital whiteboard, HDTV
- **Printer** → ผลบนกระดาษเรียก **hard copy**
  - **Inkjet** — พ่นหมึก คุณภาพดี ราคาถูก นิยมที่สุด
  - **Laser** — หลักการเดียวกับเครื่องถ่ายเอกสาร มีแบบส่วนตัวและแบบใช้ร่วมกัน
- **Audio output**: ลำโพง, หูฟัง · digital media player

## บทที่ 8 · Secondary Storage

Primary storage (RAM) ข้อมูลหายได้ ส่วน secondary storage เก็บข้อมูลถาวร

- ลักษณะที่ต้องรู้: **Media** (วัสดุที่เก็บข้อมูล), **Capacity** (ความจุ), **Storage device** (ฮาร์ดแวร์ที่อ่าน/เขียน), **Access speed / Access time** (เวลาดึงข้อมูล)
- **Hard disk**: จานโลหะซ้อนกันเรียก **platter** · จัดเก็บด้วย **track, sector, cylinder** (cylinder = track และ sector เดียวกันแต่ต่าง platter) · มีแบบ internal และ external
- **Solid-state storage**: ไม่มีจานหมุน เร็ว กินไฟน้อย แต่แพง เช่น flash memory · **USB drive** เล็ก พกพาง่าย
- **Optical disc** (CD, DVD, Blu-ray)
  - **ROM** = อ่านอย่างเดียว
  - **R** = เขียนได้ครั้งเดียว
  - **RW** = อ่าน เขียน แก้ไขซ้ำได้
- **Cloud storage**: Google Drive, OneDrive, Dropbox

## บทที่ 9 · CPU

ความเร็ว CPU คือความถี่สัญญาณนาฬิกา (Hz) และตัว CPU มี 4 แพ็กเกจ โดย LGA เป็นแบบที่ Intel ใช้ถึงปัจจุบัน

- CPU คำนวณ arithmetic/logical และควบคุมส่วนอื่นของระบบ
- **ความเร็ว** หน่วย Hz = จำนวน cycle ต่อวินาที (1 MHz = 1 ล้านครั้ง/วินาที)
  - Clock ภายใน = ความเร็วของ CPU เอง เช่น 2.8 หรือ 3.6 GHz
  - Clock ภายนอก = จังหวะของ bus: FSB, QPI, HTT, PCIe, UMI, DMI
- **Bus ของ CPU**
  - **FSB** (Front Side Bus) — CPU ↔ North Bridge/MCH ยุค Core 2 · clock จริง 100–400 MHz แต่เขียนเป็น FSB 400–1600 (ความเร็วสุทธิ)
  - **QPI** (Intel QuickPath Interconnect) — CPU ↔ chipset/IOH มาแทน FSB
  - **DMI** (Direct Media Interface) — เชื่อมแบบจุดต่อจุด CPU ↔ PCH
- **Cache** L1, L2, L3 อยู่ในตัว CPU ช่วยให้ประมวลผลเร็วขึ้น

| แพ็กเกจ | ลักษณะ | ตัวอย่าง |
|---|---|---|
| **BGA** (Ball Grid Array) | ลูกบอลเล็กบัดกรีติดบอร์ด ถอดเปลี่ยนไม่ได้ | — |
| **Cartridge (SECC)** | เสียบลง slot บนบอร์ด ใช้กับ CPU รุ่นเก่า | Celeron, Pentium II/III (Slot 1), AMD Athlon K7 (Slot A) |
| **PGA** (Pin Grid Array) | ขาอยู่ที่ตัว CPU | PPGA, OmPGA, FC-PGA |
| **LGA** (Land Grid Array) | CPU ไม่มีขา เป็นแผ่นสัมผัสกลมแบน ขาอยู่ที่ socket ล็อกด้วย Load plate + Load lever | Pentium 4 ถึงปัจจุบัน: LGA 775, 1150, 1366, 2011, 2066, 1200 |

- **อ่านสเปกบนตัว CPU** เช่น Core 2 Quad Q9450: sSpec SLAWR, 2.66 GHz, L2 cache 12 MB, Bus 1333 MHz · เช็คละเอียดได้ที่เว็บ Intel
- **รหัสท้ายรุ่น Intel**
  - โน้ตบุ๊ก: **U** ไฟต่ำ (ฝังบอร์ด อัปไม่ได้) · **Y** ไฟต่ำมาก ไม่มีพัดลม · **M** Mobile (ถอดได้) · **Q** Quad core · **H** กราฟิกแรง · **K** ปลดล็อก overclock
  - เดสก์ท็อป: **K** ปลดล็อก overclock · **F** ไม่มีกราฟิกในตัว ต้องใช้การ์ดจอแยก

## บทที่ 10 · RAM

RAM ในเครื่องเป็น DRAM แต่ละรุ่นขา ไฟ และร่องบากต่างกัน จึงใส่แทนกันไม่ได้

- RAM ทำงานคู่ CPU ตลอด เป็นที่พักข้อมูลและคำสั่งชั่วคราวรอ CPU ประมวลผล
- **SRAM** (Static RAM) — เร็วกว่า DRAM มาก ใช้ทำ **cache ใน CPU** แต่ทำความจุใหญ่ยาก แพง กินไฟ ร้อน
- **DRAM** (Dynamic RAM) — ใช้ทำ RAM หลัก เป็นแบบ Synchronous พัฒนาเป็นรุ่นตามตาราง

| รุ่น | ขา DIMM (เดสก์ท็อป) | ขา SO-DIMM (โน้ตบุ๊ก) | ไฟ (V) | ความเร็ว | หมายเหตุ |
|---|---|---|---|---|---|
| SDRAM | 168 | — | 3.3 | PC-66 / PC-100 / PC-133 | เลิกใช้หลังยุค Pentium III |
| DDR | 184 | 200 | 2.5 | DDR-266 → DDR-700 | หมดความนิยมแล้ว |
| DDR2 | 240 | 200 | 1.8 | DDR2-400 (PC2-3200) → DDR2-1066 | สูงสุด 4 GB, prefetch 4 bit |
| DDR3 | 240 | 204 | 1.5 | DDR3-800 (PC3-6400) → DDR3-1600 (PC3-12800) | สูงสุด 8 GB, prefetch 8 bit, ใส่แทน DDR2 ไม่ได้ |
| DDR4 | 288 | 260 | 1.2 | DDR4-1600 (PC4-12800) → DDR4-3200 (PC4-25600) | สูงสุด 16 GB, prefetch 16 bit |

- **โหมด RAM**: Single-channel, Dual-channel, Flex mode — สไลด์มีแต่รูป: dual-channel คือใส่ RAM เป็นคู่ในช่องสีเดียวกันให้ทำงานพร้อมกัน จึงเร็วขึ้น

## บทที่ 11 · Hard Disk

Hard disk ต่อกับบอร์ดผ่าน interface 4 แบบ และ SATA III เร็วสุดที่ 6 Gbit/s

- จานแม่เหล็กหมุนหลายพันรอบต่อนาที (**rpm** = Revolutions Per Minute เช่น 5,400 และ 7,200 rpm) มีหัวอ่านเลื่อนอ่าน/เขียน

| Interface | ส่งข้อมูล | ความเร็ว | จุดที่ต้องจำ |
|---|---|---|---|
| **IDE / ATA / PATA** | ขนาน (Parallel) | ATA-100 = 100 MB/s, ATA-133 = 133 MB/s | ขั้วต่อ 40 ขา · สายแพ 40/80 เส้น 3 หัว · ต่อ 2 ลูกบนสายเดียวต้องตั้ง **Master/Slave** ด้วย jumper |
| **SATA** | อนุกรม (Serial) | SATA I 1.5 Gbit/s (~150 MB/s) · SATA II 3 Gbit/s (~300 MB/s) · SATA III 6 Gbit/s (~600 MB/s) | port บนบอร์ด 7 ขา · ดูแลมาตรฐานโดย SATA-IO |
| **SCSI** | ขนาน (Parallel) | — | ต่อได้ 7 อุปกรณ์ (SCSI-2 ได้ 15) ผ่าน SCSI host adapter · ใช้กับ server · ถอดเปลี่ยนดิสก์ขณะเครื่องทำงานได้ |
| **SAS** (Serial Attached SCSI) | อนุกรม (Serial) | — | มาแทน SCSI แบบเดียวกับ ATA → SATA · ใช้กับอุปกรณ์ SATA ได้ |

- **SSD** (Solid State Drive) — ใช้ flash memory เก็บข้อมูลถาวร เร็วมาก
- **HDD ภายนอก** — USB 2.0, FireWire (IEEE 1394), **eSATA** (เร็วเท่าแบบติดในเครื่อง) · **NAS** (Network Attached Storage) = ดิสก์ที่ต่อเข้าเครือข่าย
- **RAID** (Redundant Array of Inexpensive Disks) = เอา HDD ตั้งแต่ 2 ลูกมาทำงานรวมเป็นลูกเดียว
  - **RAID 0** — อ่าน/เขียนเร็วขึ้น แต่ถ้าลูกเดียวเสีย ข้อมูลอาจหายทั้งหมด
  - **RAID 1** — เขียนซ้ำ 2 ลูก ปลอดภัยแต่ไม่เร็วขึ้น ค่าใช้จ่าย 2 เท่า
  - **RAID 5** — ใช้อย่างน้อย **3 ลูก** สเปกเท่ากัน ได้ทั้งความเร็วและสำรอง ลูกหนึ่งเสียยังทำงานต่อได้

## บทที่ 12 · Mainboard, Case และ Power

Chipset กำหนดคุณสมบัติเกือบทั้งหมดของเมนบอร์ด จึงเป็นหลักในการเลือกซื้อเมนบอร์ด

- **Form factor** = มาตรฐานขนาดและตำแหน่งชิ้นส่วนบนบอร์ด มีผลกับการออกแบบ case
  - **AT** (Advanced Technology) — ใช้ใน IBM PC รุ่นแรก
  - **ATX** (Advanced Technology eXtended) — Intel ออกแบบปี **1995** ใช้แพร่หลายถึงปัจจุบัน
  - Micro ATX, Flex ATX, BTX และ **ITX** (Mini-ITX 17 × 17 cm, Nano-ITX 12 × 12 cm, Pico-ITX 10 × 7.2 cm)
- **CPU socket** — CPU แต่ละยี่ห้อ/รุ่นใช้ socket ต่างกัน · **RAM slot** — DDR3 กับ DDR4 ร่องบากต่างกัน ใส่แทนกันไม่ได้
- **Chipset** (North Bridge/MCH + South Bridge/ICH) — กำหนด CPU และ socket ที่รองรับ, ชนิด RAM, ความเร็ว bus และการขยายระบบ · FSB คือ bus ที่เชื่อม CPU กับ chipset ตัวหลัก

ข้อมูลระหว่าง CPU กับ RAM และการ์ดจอวิ่งผ่าน North Bridge ส่วน PCI slot และขั้วต่อดิสก์อยู่ฝั่ง South Bridge

- **Slot การ์ด**
  - **PCI / PCI-X** — LAN, modem, sound, SATA, SSD, SCSI, USB, capture card
  - **AGP** (Accelerated Graphics Port, สูงสุด 8X) — สำหรับการ์ดจอ ถูกแทนด้วย **PCIe x16**
  - PCIe x16 bandwidth: v1.1 = 8 GB/s, v2.0 = 16 GB/s, v3.0 = 32 GB/s · มี slot ขนาด x1, x4, x16
- **BIOS** (Basic Input/Output System) — ชิปบนบอร์ด เก็บโปรแกรมพื้นฐาน ตรวจความพร้อมอุปกรณ์และ boot ระบบ
- **BIOS battery** — เลี้ยงไฟ CMOS ถ้าใกล้หมด นาฬิกาเพี้ยนและค่า BIOS ไม่ถูกบันทึก
- **Power connector** — รับไฟ ±5 V, ±12 V และ +3.3 V จาก Power Supply
- **Front panel connector**
  - Reset SW = ปิดแล้วเปิดใหม่ · Power SW = เปิดเครื่อง (กดค้าง 4–5 วินาที = บังคับปิด)
  - Power LED สีเขียว = เครื่องทำงาน · HDD LED กะพริบ = ดิสก์กำลังทำงาน · Speaker = เสียงเตือนจาก BIOS
- **ขั้วต่อบนบอร์ด** — IDE (สายแพ 40/80 เส้น) · SATA 7 ขา · Floppy (FDD) 34 ขา ต่อได้ 2 ไดรฟ์
- **Case**
  - Full Tower — ใหญ่ หนัก วางพื้น นิยมทำ server
  - Medium Tower — ขนาดกลาง นิยมที่สุดในปัจจุบัน
  - Mini Tower — สำหรับบอร์ดเล็ก 2–3 slot
  - Desktop — วางแนวนอน วางจอบน case · Mini PC — เล็ก วางได้ทั้งแนวนอนและแนวตั้ง
- **Power Supply** — แปลง **AC 220 V → DC 3.3 V, 5 V, 12 V** · ปัจจุบันควร **400 W ขึ้นไป** (คำนวณได้ที่ outervision.com)
- **UPS** (Uninterruptible Power Supply) — สำรองไฟและปรับแรงดันอัตโนมัติ · PC ทั่วไปเริ่มที่ **500 VA** สำรองได้ประมาณ 5–10 นาที

## แบบทดสอบ 15 ข้อ

ทำให้ครบทุกข้อก่อน แล้วค่อยตรวจกับเฉลยด้านล่าง

1. ระบบสารสนเทศมี 5 ส่วน ส่วนไหนสำคัญที่สุด?
  - ก. Hardware
  - ข. Software
  - ค. People (บุคลากร/ผู้ใช้)
  - ง. Data
2. Internet เริ่มต้นในปี 1969 จากโครงการของสหรัฐฯ ที่ชื่อว่าอะไร?
  - ก. ARPANET
  - ข. CERN
  - ค. WWW
  - ง. Ethernet
3. การประมูลสินค้าออนไลน์ระหว่างคนทั่วไปด้วยกัน เป็น E-commerce ประเภทใด?
  - ก. B2C
  - ข. B2B
  - ค. B2G
  - ง. C2C
4. ภาพที่ถูกเก็บเป็นจุดเล็กๆ ที่เรียกว่า pixels คือภาพแบบใด?
  - ก. Vector image
  - ข. Bitmap / Raster image
  - ค. Clip art
  - ง. Graphics suite
5. ถ้ากด Restart เครื่องที่เปิดอยู่แล้ว เรียกว่าการ boot แบบใด?
  - ก. Warm boot
  - ข. Cold boot
  - ค. Embedded boot
  - ง. Network boot
6. ส่วนของ CPU ที่คำนวณทางคณิตศาสตร์และเปรียบเทียบทางตรรกะคือข้อใด?
  - ก. Control unit
  - ข. Cache memory
  - ค. ALU (Arithmetic-Logic Unit)
  - ง. Bus line
7. หน่วยความจำแบบใดที่ข้อมูลหายเมื่อปิดเครื่องหรือไฟดับ (volatile)?
  - ก. ROM
  - ข. RAM
  - ค. Flash memory
  - ง. Hard disk
8. อุปกรณ์ที่อ่าน "เครื่องหมาย" ด้วยแสง เช่น เครื่องตรวจกระดาษคำตอบแบบฝนวงกลม คือข้อใด?
  - ก. MICR
  - ข. OCR
  - ค. OMR
  - ง. UPC
9. แผ่น DVD-R มีความสามารถแบบใด?
  - ก. อ่านได้อย่างเดียว
  - ข. ลบและเขียนซ้ำได้หลายครั้ง
  - ค. เก็บข้อมูลไว้บน cloud
  - ง. เขียนได้ครั้งเดียว
10. CPU Intel ที่ลงท้ายด้วย F เช่น Core i5-10400F หมายความว่าอะไร?
  - ก. ปลดล็อกให้ overclock ได้
  - ข. ไม่มีกราฟิกในตัว ต้องใช้การ์ดจอแยก
  - ค. ประหยัดไฟสำหรับโน้ตบุ๊ก
  - ง. มี 4 คอร์
11. RAM DDR4 แบบ DIMM (เดสก์ท็อป) มีกี่ขาและใช้ไฟกี่โวลต์?
  - ก. 184 ขา 2.5 V
  - ข. 240 ขา 1.8 V
  - ค. 240 ขา 1.5 V
  - ง. 288 ขา 1.2 V
12. SATA III มีอัตรารับส่งข้อมูลเท่าไร?
  - ก. 1.5 Gbit/s (~150 MB/s)
  - ข. 3 Gbit/s (~300 MB/s)
  - ค. 6 Gbit/s (~600 MB/s)
  - ง. 133 MB/s
13. RAID แบบใดที่อ่าน/เขียนเร็วขึ้น แต่ถ้าดิสก์ลูกใดลูกหนึ่งเสีย ข้อมูลอาจหายทั้งหมด?
  - ก. RAID 0
  - ข. RAID 1
  - ค. RAID 5
  - ง. NAS
14. ชิ้นส่วนใดบนเมนบอร์ดที่กำหนดคุณสมบัติเกือบทั้งหมด เช่น CPU ที่รองรับ ชนิด RAM และความเร็ว bus?
  - ก. BIOS chip
  - ข. Chipset
  - ค. CPU socket
  - ง. Power connector
15. Power Supply ทำหน้าที่อะไร?
  - ก. แปลงไฟ AC 220 V เป็น DC 3.3 V, 5 V และ 12 V
  - ข. แปลงไฟ DC เป็น AC 220 V
  - ค. สำรองไฟเวลาไฟดับได้ 5–10 นาที
  - ง. เก็บค่าการตั้งค่า BIOS
