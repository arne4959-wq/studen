# ขั้น 5 — เลือกวิชา / บทเรียน / Summary

> วางพรอมต์ด้านล่างนี้ให้ AI

---

อ่านกฎกลาง และ `design-ref/Subjects.html`, `DesktopHome.html`, `Summary.html`, `DesktopSummary.html`, `StateEmpty.html` แล้วทำ **ขั้น 5 เท่านั้น**

## งาน
1. `subjects.html` + `js/pages/subjects.js`
   - เรียก `getSubjects()` วาดการ์ดวิชา (ชื่อ, `done/total`, แถบ `asciiBar`) วิชาที่เลือกมีขอบเขียว 2px (ค่าเริ่มต้น = วิชาแรก จำวิชาที่เลือกล่าสุดใน `store`)
   - กดการ์ดวิชา ➜ เรียก `getLessons(id)` แล้วแสดงรายการแบบไฟล์ `01 present_simple ✓ done / ● running / ○ todo` ตามดีไซน์ (ข้อความสถานะผ่าน i18n)
   - วิชาที่ไม่มีบทเรียน ➜ แสดงสถานะ "ไม่มีข้อมูล" (`const ບົດຮຽນ = []`) พร้อมปุ่มกลับ
   - ทั้งสองส่วนใช้ `withState` (loading/error/empty) แยกกัน: โหลดรายการวิชาล้ม ≠ โหลดบทเรียนล้ม
   - กดบทเรียน ➜ `summary.html?lesson=<id>` (ส่งชื่อวิชาไปด้วยเพื่อแสดงชื่อบน header)
   - จอคอม: การ์ดวิชาเรียงเป็นกริด ใต้ลงมาเป็นรายการบทเรียน (ตาม `DesktopHome.html`) แถวบทเรียน "running" มีปุ่ม `$ run`
2. `summary.html` + `js/pages/summary.js`
   - อ่าน `lesson` จาก URL (ไม่มี/ผิด ➜ ไปหน้า 404 ของขั้น 7 ชั่วคราวให้แสดงสถานะ error)
   - แสดง: ป้าย "สรุป · อ่าน N นาที", ชื่อบท `# Past Simple`, ข้อความ intro, กล่องโค้ด `keyPoints`/`codeSample` (ไฮไลต์สีคีย์เวิร์ดด้วย class ไม่ใช่ library), ตาราง `from → to`
   - ปุ่ม `$ run quiz --questions=N` ➜ `quiz.html?lesson=<id>` (ติดท้ายหน้าบนมือถือ, เป็นการ์ดด้านขวาบนจอคอมตาม `DesktopSummary.html`)
3. ใช้ `mountShell` ทุกหน้า, ปุ่มย้อนกลับกลับไปหน้าก่อนหน้า
4. ข้อความใหม่เข้า i18n 3 ภาษา (ส่วนเนื้อหาบทเรียนมาจาก API ไม่ต้องแปล)

## ห้าม
- ห้ามฝังเนื้อหาบทเรียนในโค้ด ต้องมาจาก `api.js` เท่านั้น
- ห้ามใช้ `innerHTML` กับเนื้อหาจาก API (ถ้าต้องไฮไลต์โค้ด ให้สร้าง `<span class>` ด้วย `el()`)
