# ขั้น 6 — Quiz / คะแนน / เฉลย

> วางพรอมต์ด้านล่างนี้ให้ AI

---

อ่านกฎกลาง และ `design-ref/Quiz.html`, `DesktopQuiz.html`, `Score.html`, `DesktopScore.html`, `Review.html`, `DesktopReview.html` (อ่านสคริปต์ท้ายไฟล์เพื่อดูลอจิกสถานะ) แล้วทำ **ขั้น 6 เท่านั้น**

## งาน
1. `quiz.html` + `js/pages/quiz.js`
   - `getQuiz(lessonId)` ➜ แสดงทีละข้อ: ส่วนหัว `test n/N` + เปอร์เซ็นต์ + แถบตัวอักษร, การ์ดโค้ด `question_0n.js` ที่แสดงคำถาม, ตัวเลือก A–D เป็น `<button aria-pressed>`
   - ปุ่ม `← prev()` (ซ่อนที่ข้อแรก), `next() →` (**ล็อกจนกว่าจะเลือกตัวเลือก** ใช้ `aria-disabled` และกดไม่ได้จริง), ข้อสุดท้ายเปลี่ยนเป็น `submit()`
   - ปุ่มย้อนกลับด้านบน/ปุ่ม exit ➜ `confirmDialog` "ອອກຈາກ Quiz ບໍ?" (ปุ่ม continue / `$ exit`)
   - เก็บคำตอบและข้อปัจจุบันใน `sessionStorage` ของบทเรียนนั้น: รีเฟรชแล้วทำต่อจากเดิม ออกด้วย exit แล้วล้าง
   - คีย์ลัด: ตัวเลข 1–4 หรือ A–D เลือกคำตอบ, Enter ไปต่อ (เมื่อไม่ถูกล็อก) — ต้องไม่ชนกับการพิมพ์ในช่องกรอก
   - `submit()` ➜ `submitQuiz()` แสดงสถานะกำลังส่ง กดซ้ำไม่ได้ ถ้าล้มให้แสดง error + ลองใหม่โดยไม่เสียคำตอบ สำเร็จ ➜ เก็บผลใน `sessionStorage` แล้วไป `score.html?lesson=<id>`
   - จอคอม: เลย์เอาต์ตาม `DesktopQuiz.html` (ตัวเลือก 2 คอลัมน์เมื่อกว้างพอ)
2. `score.html` + `js/pages/score.js`
   - อ่านผลจาก sessionStorage (ไม่มี ➜ กลับไปหน้าบทเรียนนั้น) แสดง `$ npm test`, แถว `PASS/FAIL` ต่อข้อ, `expected/received` ของข้อที่ผิด, สรุป `N passed, M failed`, เปอร์เซ็นต์ใหญ่
   - ปุ่ม `$ git diff answers` ➜ `review.html`, `cd ../subjects`, `$ stats`
3. `review.html` + `js/pages/review.js`
   - มือถือ: ชิปกรอง "ທັງໝົດ N / ຜິດ M", รายการข้อแบบกาง/พับ (`aria-expanded`) ข้อที่ผิดกางเป็นค่าเริ่มต้น แสดงคำถาม, diff `- ของคุณ` / `+ ที่ถูก`, กล่อง `// ເຫດຜົນ`
   - จอคอม: รายการซ้าย รายละเอียดขวา (ตามดีไซน์) เลือกข้อด้วยคีย์บอร์ดได้
   - ปุ่ม `$ retry quiz` (ล้างคำตอบเก่า เริ่มใหม่), `cd ../subjects`
4. เมื่อส่ง Quiz แล้ว ให้ปรับ mock ให้บทเรียนนั้นเปลี่ยนสถานะเป็น done และคะแนนล่าสุดไปปรากฏใน dashboard (ใน mock เก็บใน localStorage)
5. i18n 3 ภาษา

## ห้าม
- ห้ามคำนวณคะแนนในหน้าเว็บ ต้องใช้ผลจาก `submitQuiz()` เท่านั้น (Backend จริงจะเป็นคนตรวจ)
- ห้ามเอาเฉลยไปเก็บฝั่งหน้าเว็บก่อนส่ง
