# ชุดพรอมต์สร้างเว็บ «ຮຽນງ່າຍ» ใน VS Code (ทีละขั้น)

## ใช้ภาษาอะไร

**HTML + CSS + JavaScript ล้วน (ไม่ใช้ framework ไม่มี build)**

เหตุผล: ตรงกับแผนงานของคุณ (CSS variables, `@media`, `fetch()`, mock JSON) เรียนรู้ง่าย แก้เองได้ ไม่ต้องติดตั้งอะไรเพิ่ม และเชื่อม Backend ได้ตรง ๆ

| ส่วน | เลือกใช้ |
|---|---|
| โครงหน้า | HTML หลายหน้า (1 หน้า = 1 ไฟล์ `.html`) |
| สไตล์ | CSS ล้วน + CSS variables (ธีมมืด/สว่าง) |
| โลจิก | JavaScript ES modules (`<script type="module">`) |
| ข้อมูลช่วงแรก | ไฟล์ mock JSON ในโฟลเดอร์ `data/` |
| หลายภาษา | ไฟล์ `i18n/lo.json`, `th.json`, `en.json` |
| รันดู | ส่วนขยาย **Live Server** ใน VS Code (หรือ `npx serve`) |
| เชื่อม Backend | `fetch()` ผ่านไฟล์เดียว `js/api.js` |

## เตรียมก่อนเริ่ม (ทำครั้งเดียว)

1. สร้างโฟลเดอร์โปรเจกต์ใหม่ เช่น `hianngai-web` แล้วเปิดด้วย VS Code
2. ติดตั้งส่วนขยาย **Live Server**
3. คัดลอกโฟลเดอร์ `design-ref/` (ในชุดนี้) ไปไว้ในโปรเจกต์ AI จะอ่านโค้ดดีไซน์จริงจากตรงนี้
4. `git init` แล้ว commit ว่าง ๆ ไว้ (จะได้ย้อนกลับได้ถ้า AI ทำพลาด)

## วิธีใช้

1. เปิด `step-00-context.md` ➜ คัดลอกทั้งไฟล์ไปบันทึกเป็นไฟล์กฎของโปรเจกต์
   - ใช้ Claude Code: ชื่อ `CLAUDE.md` ที่รากโปรเจกต์
   - ใช้ GitHub Copilot: `.github/copilot-instructions.md`
   - ใช้ตัวอื่น: วางเป็น `PROJECT.md` แล้วบอก AI ให้อ่านก่อนทุกครั้ง
2. วางพรอมต์ **ทีละไฟล์ตามลำดับ** `step-01` ➜ `step-09`
3. แต่ละขั้นจบด้วยรายการ "ตรวจรับ" ให้ลองเปิดดูจริงก่อน ผ่านแล้วค่อย `git commit` และไปขั้นต่อไป
4. ถ้าขั้นไหนมีปัญหา อย่าข้าม ให้บอก AI ว่า "แก้ข้อ X ในรายการตรวจรับ" แล้วค่อยไปต่อ

## ลำดับขั้น

| ขั้น | ทำอะไร | ได้อะไร |
|---|---|---|
| 00 | ไฟล์กฎกลาง | AI รู้บริบทและกติกาทั้งโปรเจกต์ |
| 01 | โครง + ธีม + หลายภาษา | หน้า `styleguide.html` สลับมืด/สว่าง ลาว/ไทย/อังกฤษได้ |
| 02 | ข้อมูลจำลอง + `api.js` | ดึงข้อมูลได้ มีโหมดช้า/ผิดพลาด/ว่างไว้ทดสอบ |
| 03 | ชิ้นส่วนใช้ซ้ำ + โครงหน้า | ปุ่ม การ์ด ฟอร์ม หน้าต่างยืนยัน แถบเมนู |
| 04 | Login / สมัคร / ลืมรหัสผ่าน | ระบบผู้ใช้ + ตัวกั้นหน้า |
| 05 | เลือกวิชา / บทเรียน / Summary | โฟลว์เรียน |
| 06 | Quiz / คะแนน / เฉลย | โฟลว์ทำข้อสอบครบ |
| 07 | สถิติ / โปรไฟล์ / ตั้งค่า / 404 | หน้าที่เหลือ |
| 08 | ขัดเกลา + ตรวจ | Responsive, สีสว่าง, เข้าถึงง่าย, ตรวจข้อความหลายภาษา |
| 09 | เชื่อม API จริง | เปลี่ยนจาก mock เป็น Backend |

## ข้อควรรู้

- พรอมต์ยังไม่ได้ทดสอบกับเครื่องมือ AI ของคุณ ถ้า AI ทำเกินหรือขาด ให้ตัดต่อปรับได้
- ชื่อ API ในขั้น 02 เป็นตัวอย่าง ต้องตกลงกับคนทำ Backend ก่อนขั้น 09 (หรือตั้งแต่ขั้น 02 ยิ่งดี)
- คำภาษาไทยและอังกฤษใน `th.json`/`en.json` เป็นร่างแรกจาก AI ควรให้เจ้าของภาษาอ่านตรวจ
- หน้าโหมดสว่างไม่ต้องทำแยกต่างหาก ใช้ชุดสีสว่างสลับด้วย CSS variables
