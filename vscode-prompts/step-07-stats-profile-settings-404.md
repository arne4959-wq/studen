# ขั้น 7 — สถิติ / โปรไฟล์ / ตั้งค่า / 404

> วางพรอมต์ด้านล่างนี้ให้ AI

---

อ่านกฎกลาง และ `design-ref/Dashboard.html`, `DesktopDash.html`, `Profile.html`, `DesktopProfile.html`, `Language.html`, `ChangePassword.html`, `DesktopSettings.html`, `NotFound.html`, `DesktopNotFound.html` แล้วทำ **ขั้น 7 เท่านั้น**

## งาน
1. `stats.html` + `js/pages/stats.js`
   - `getDashboard()` ➜ การ์ดตัวเลข (`lessons 4 / 18`, `avgScore 90%`, `quizzes 9`) สไตล์ JSON, **ตารางกิจกรรม 4 สัปดาห์** (7 คอลัมน์ × 4 แถว) ระดับสี `--heat-0..4` คำนวณระดับจาก `count`, วันนี้มีเส้นขอบเน้น, มี legend น้อย→มาก และ `role="img"` + `aria-label` สรุปเป็นข้อความ
   - รายการคะแนนล่าสุดแบบ `git log` (`รหัสสั้น  ชื่อบท  4/5`) กดแล้วไป `review.html` ของบทนั้น (ถ้าไม่มีผลในเครื่องให้แสดงข้อความว่ายังไม่มีเฉลย)
   - `withState` ครบ (loading/error/empty: ยังไม่เคยทำ Quiz ➜ ข้อความชวนไปเรียน)
2. `profile.html` + `js/pages/profile.js`
   - `getMe()` ➜ อวาตาร์ตัวอักษรแรก, ชื่อ, อีเมล, สถิติย่อ; รายการตั้งค่า: ภาษา (ลิงก์ ➜ `language.html`), โหมดสี (สวิตช์พระจันทร์/อาทิตย์ ใช้ `toggleTheme()` และแสดงข้อความ "ມືດ/ສະຫວ່າງ" ตามสถานะจริง), เปลี่ยนรหัสผ่าน (ลิงก์ ➜ `change-password.html`)
   - ปุ่ม `$ logout` ➜ `confirmDialog` (danger) ➜ เรียก `logout()` ล้าง token และข้อมูลชั่วคราว ➜ `login.html`
3. `language.html` + `js/pages/language.js`: ตัวเลือก ລາວ / ไทย / English แบบ radio (`aria-pressed` หรือ `<input type=radio>` จริง) เปลี่ยนแล้ว **มีผลทันทีทั้งหน้า** ไม่ต้องกดบันทึก
4. `change-password.html` + `js/pages/change-password.js`: ฟอร์ม 3 ช่อง ตรวจฝั่งหน้าเว็บ (≥8 ตัว, ใหม่ตรงยืนยัน, ไม่ซ้ำรหัสเดิม), เรียก `changePassword()`, สำเร็จแสดง `✓ ປ່ຽນລະຫັດຜ່ານແລ້ວ` (`role="status"`), `wrong_password` แสดง error ใต้ช่องปัจจุบัน
   - จอคอม: ตามบอร์ด `DesktopSettings.html` ที่รวมภาษา+เปลี่ยนรหัสผ่านเป็นสองการ์ดข้างกัน ให้ทำเป็นหน้า `settings.html` เดียวสำหรับ ≥768px ได้ โดยมือถือยังแยกสองหน้า (ถ้าซับซ้อนเกินไป ให้คงเป็นสองหน้าและแจ้งผม)
5. `404.html`: สไตล์เทอร์มินัล `bash: cd: /... No such file or directory`, ตัวเลข 404 ใหญ่, ปุ่ม `cd ~` ไปหน้าแรก ใช้เมื่อ URL ผิด/พารามิเตอร์บทเรียนหายหรือไม่มีอยู่จริง (ปรับจุดที่ขั้น 5–6 ชั่วคราวใช้สถานะ error ให้ชี้มาหน้านี้)
6. i18n 3 ภาษา

- [ ] เปลี่ยนภาษาแล้วทั้งเว็บเปลี่ยน (ทุกหน้าที่ทำมาแล้ว) และรีเฟรชแล้วคงเดิม
