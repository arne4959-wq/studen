## งาน
1. `js/config.js`: ตั้ง `USE_MOCK = false` และ `API_BASE` ตามที่ให้ (อ่านจากค่าเดียว ห้ามกระจายหลายที่) รองรับการสลับกลับเป็น mock ด้วยพารามิเตอร์ `?mock=1` ในโหมดพัฒนาเท่านั้น
2. ปรับ `js/api.js` ให้ตรงสัญญาจริง: ถ้าชื่อฟิลด์ต่าง ให้ **แปลงในชั้น api.js ชั้นเดียว** (adapter) หน้าอื่นต้องไม่ต้องแก้
3. ตรวจและจัดการ: CORS (ถ้าเว็บกับ API คนละโดเมน ให้บอกผมว่าฝั่ง Backend ต้องเปิดอะไร), หมดเวลาเชื่อมต่อ (timeout 15 วินาที ด้วย `AbortController`), 401 ➜ ล้าง session กลับ login, 5xx/เครือข่ายล่ม ➜ สถานะ error + retry, รูปแบบข้อผิดพลาดที่ไม่ใช่ JSON
4. ตรวจ `getQuiz` ว่าไม่มีเฉลยจริงในการตอบของ Backend ถ้ามี ให้แจ้งผม (เป็นช่องโหว่ฝั่ง Backend)
5. ทดสอบโฟลว์เต็มกับ Backend จริง: สมัคร → login → เลือกวิชา → อ่านสรุป → Quiz → คะแนน → เฉลย → สถิติ → เปลี่ยนรหัสผ่าน → logout และทำรายการ "ความต่างจากสัญญา" ที่พบ
6. ลบ/ย้ายไฟล์ mock ที่ไม่ใช้แล้วไปโฟลเดอร์ `dev/` (ห้ามลบทิ้ง) และอัปเดต README

## ห้าม
- ห้ามแก้หน้า UI ถ้าไม่จำเป็น, ห้ามเก็บรหัสผ่าน/ข้อมูลส่วนตัวใน localStorage นอกจาก token
- ห้ามเดาโครงสร้างข้อมูลที่ไม่ได้รับ ถ้าไม่ชัดให้ถามผม

## ตรวจรับ
- [ ] ทำโฟลว์เต็มกับ Backend จริงได้ ไม่มี error ใน Console
- [ ] ปิดอินเทอร์เน็ต/ปิดเซิร์ฟเวอร์ แล้วทุกหน้าแสดง error + retry (ไม่ขาวทั้งหน้า)
- [ ] token หมดอายุ ➜ ถูกส่งไป login พร้อมข้อความเซสชันหมดอายุ
- [ ] `grep` หา `localhost` และ URL ตายตัวในโค้ดแล้วไม่พบนอก `config.js`
- [ ] รายการ "ความต่างจากสัญญา" ถูกส่งให้คนทำ Backend
